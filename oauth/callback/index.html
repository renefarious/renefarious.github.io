Return to the app to sign in

Your browser opened this page instead of returning to Renefarious Cloud. Sign-in needs to finish in the app.

  1. Check that Renefarious Cloud is installed.
  2. In Android Settings, open its App info, then Open by default, and enable Open supported links. Names may vary by device.
  3. Return to Renefarious Cloud and start sign-in again.

You can close this tab. If sign-in still does not return to the app, use the API Token option in Renefarious Cloud.
