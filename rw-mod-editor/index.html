Features

What you can do.

Everything you need to mod Rusted Warfare units, all in one place.

RWME Workshop & Sharing

Browse and download mods. Features fast multi-threaded downloads, offline support, and compact .rwmod packaging.

Visual INI Editing

View sections in a clean, collapsible card list. Easily add, edit, or drag-and-drop to reorder sections.

Smart Autocomplete

Context-aware suggestions adapt to your current section to help you write correct keys faster.

Code Library Reference

A built-in, browsable list of all known Rusted Warfare property keys and their detailed descriptions.

Project Manager

Manage your mod files cleanly. Save edits, duplicate files, and preserve original file layouts and comments.

Ready-Made Templates

Kickstart your modding journey with pre-filled Unit and Building templates to get the core structure instantly.

Font Customization

Choose clean built-in fonts or load your own custom font file, complete with a live size preview slider.

Leaderboards & Profiles

Track your standing on the Global Leaderboard with live updates for karma points, follower counts, and online presence.
